# StudySphere

StudySphere is an enhanced Learning Management System (LMS) developed using the MERN stack (MongoDB, Express.js, React, Node.js). The platform enables students to discover and enroll in courses, instructors to publish and manage educational content, and administrators to manage users and platform operations.

Core capabilities include secure authentication, role-based access control, course management, progress tracking, multimedia content support, and AI-powered features such as quiz generation and learning assistance. The project follows modern software engineering practices with a responsive user interface, RESTful APIs, cloud storage integration, and a scalable architecture.
